# Tela de Login

Uma interface de autenticação simples e elegante, desenvolvida com HTML, CSS e JavaScript.

## Descrição

Este projeto é uma página de login inicial, pensada como base para estudos, protótipos e evolução para aplicações web mais completas. A estrutura foi organizada para facilitar a personalização visual e futuras implementações de autenticação real.

### Recursos previstos

- layout centralizado em tela
- área de login com e-mail e senha
- seção para login com redes sociais
- estrutura pronta para expansão
- design responsivo e fácil de personalizar

## Estrutura do projeto

- `login.html` — estrutura da página e conteúdo HTML
- `styles.css` — estilos visuais da interface
- `script.js` — lógica complementar para interações e validações
- `README.md` — documentação do projeto

## Como executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `login.html` em um navegador.
3. Se quiser alterar o visual, edite `styles.css`.
4. Para adicionar interações, utilize `script.js`.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Status do projeto

Este é um projeto inicial em desenvolvimento, com foco em layout e aprendizado de front-end. Ele pode ser expandido com:

- validação de formulário
- mostrar/ocultar senha
- autenticação com backend
- responsividade para mobile
- tema claro/escuro
- integração com APIs
